## 问题与确认

| ID | 级别 | 发现 | 用户确认与处理 |
|----|:----:|------|--------------|
| SA-001 | P1 | 用户多选时仅能逐张卡片勾选，缺乏一键全选入口 | 在批量操作栏“移动”按钮左侧新增全选按钮，点击全选当前视图所有可视书签 |
| SA-002 | P2 | 当前可视书签已全部选中时的后续交互意图 | 全选按钮动态切换为“取消全选（Deselect all）”，点击取消当前可视书签的选中，同时右侧保留“清除选择”兜底 |
| SA-003 | P2 | 在选择模式（selectionMode）下未选任何书签时批量栏隐藏 | 调整批量栏展示时机：在 `composeSelectedIds.length > 0 || (selectionMode && visibleBookmarks.length > 0)` 下展示，提供即时全选能力 |

## 一致性审查

- **数据模型**：零新增或修改持久化字段，纯前端选择集合操作，无数据库迁移或信封破坏。
- **API 与 Go 后端**：不涉及后端 Go IPC 或 Supabase 接口变更。
- **国际化与硬编码门禁**：文案由 `i18n/catalogs.ts` 集中登记（`content.selectAll` / `content.deselectAll`），通过 `ui-language-audit` 门禁。
- **性能与复杂度**：采用纯函数与 Set 进行去重和过滤，复杂度 $O(N)$，对于上千条书签毫无卡顿。
- **可访问性**：包含明确的 `aria-label` 与语义化 `button`。
